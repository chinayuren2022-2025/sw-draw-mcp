# 光学零件知识库（optical.md）

> 供 LLM 在意图识别阶段加载。所有计算与查表由 Python 确定性执行，LLM 只做提取与选择。

## 1. 透镜类型（LLM 提取的 type 枚举）

| 中文说法 | type 值 | 说明 |
|---|---|---|
| 平凸透镜 / 平凸 | plano_convex | 一面平面一面球面凸面 |
| 双凸透镜 / 双凸 | biconvex | 两面球面凸面（v2 支持） |
| 平凹透镜 / 平凹 | plano_concave | （v2 支持） |
| 弯月透镜 | meniscus | （v2 支持） |

## 2. 曲率半径公式（薄透镜近似，单球面）

- 平凸：R = f × (n - 1)
  - f 为有效焦距（mm），n 为材料折射率 n_d（587.6nm）
- 双凸：R1 = -R2 = 2f × (n - 1)

注意：这是**薄透镜/单面近似**，用于首版建模。精密设计需用透镜制造商公式
1/f = (n-1)×(1/R1 - 1/R2 + (n-1)²×t_c/(n×R1×R2)) 迭代修正，属于 v2 功能决策点。

## 3. 标准直径系列（mm）

3, 5, 6, 8, 10, 12.5, 15, 18, 20, 25, 30, 35, 40, 50, 60, 75, 100

约束规则：用户给定直径 D 若不在系列中，取**向上最接近**的标准值，并在参数确认时提示。

## 4. 中心厚度表（按直径查表，标准公差等级）

| 直径 D (mm) | 中心厚度 t_c (mm) |
|---|---|
| D ≤ 6 | 1.5 |
| 6 < D ≤ 12.5 | 2.5 |
| 12.5 < D ≤ 25 | 4.0 |
| 25 < D ≤ 50 | 5.0 |
| D > 50 | 6.0 |

精密公差等级：t_c 取表值 × 0.8，且边缘厚度要求提高至 ≥ 1.5mm。

## 5. 加工约束（硬性）

- 边缘厚度 t_e = t_c - sag ≥ 1.0mm（标准）/ 1.5mm（精密）；不满足时自动加厚 t_c 至满足
- sag = R - √(R² - (D/2)²)（球面矢高）
- 凸面球径比校验：R / (D/2) ≥ 0.85（半球告警阈值）
- 倒角：圆柱边与平面交线处 C0.3（D≤50）/ C0.5（D>50）

## 6. 公差等级（LLM 提取 tolerance 枚举）

| 说法 | tolerance |
|---|---|
| 默认 / 未说明 | standard |
| 精密 / 高精度 | precision |

## 7. 材料约束

- 透镜材料必须在 materials.md 的光学玻璃表中；未知材料→询问用户，不得猜折射率。
