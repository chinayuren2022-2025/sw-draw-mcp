# 离线部署说明（Ubuntu 服务器无法联网时）

## 1. 总体原则

服务器不能访问互联网，因此所有安装包都必须在**另一台能联网的电脑**上下载，再通过以下方式传到服务器：

- USB 移动硬盘 / U 盘
- 局域网共享 / SCP / rsync
- 内网 HTTP 服务 / FTP

推荐局域网 SCP 方式：

```bash
# 在联网电脑上下载好后，通过内网传到服务器
scp file.iso user@server_ip:/data/iso/
```

## 2. Windows 虚拟机镜像下载

| 镜像 | 下载地址 | 说明 |
|---|---|---|
| Windows 10/11 ISO | https://www.microsoft.com/software-download/windows10 或 /windows11 | 官方免费下载，用于安装虚拟机 |
| Windows Server ISO | https://www.microsoft.com/evalcenter/ | 如果有服务器版授权，也可使用 |

> 下载时选择“ISO 文件”，不要选 Media Creation Tool 的可执行文件（除非你打算在 Windows 上制作）。

## 3. SolidWorks 2018 安装包

- 来源：SolidWorks 官方订阅门户、代理商、公司已有的安装介质。
- 服务器不能联网，只能从能联网的电脑下载 SolidWorks 2018 安装镜像。
- 安装包通常是 ISO 或解压后的安装目录，传到服务器后挂载到 Windows 虚拟机中安装。

## 4. 免费虚拟机软件推荐

### 首选：KVM/QEMU（性能最好）

- Linux 原生，免费开源。
- 性能接近裸机，支持硬件虚拟化（需要 CPU 支持 VT-x/AMD-V）。
- Ubuntu 上安装命令：
  ```bash
  sudo apt install qemu-system-x86 qemu-utils libvirt-daemon-system libvirt-clients virtinst virt-manager
  ```

### 备选：Proxmox VE

- 基于 Debian + KVM，带 Web 管理界面，适合多虚拟机管理。
- 但需要单独安装一个 Proxmox 系统，离线安装更复杂。

### 如果只是简单使用

- `virt-manager`（图形界面）管理 KVM 虚拟机。

> 在无法联网的服务器上，如果 apt 源不可用，需要从联网电脑下载对应的 `.deb` 包及其依赖，再用 `dpkg -i` 安装，或使用本机已有的离线 apt 镜像。

## 5. Python 与 Python 包离线安装

### 5.1 Windows 虚拟机内的 Python

- 在联网电脑下载 Python 安装包：
  - https://www.python.org/downloads/windows/
  - 推荐 Python 3.12 或 3.11
- 传到 Windows 虚拟机后双击安装。

### 5.2 Python 依赖离线包

在联网电脑上执行：

```bash
pip download -r requirements.txt -d wheels/
pip download -r requirements-cv.txt -d wheels/
```

然后把 `wheels/` 目录传到 Windows 虚拟机，安装：

```bat
python -m pip install --no-index --find-links=D:\wheels -r D:\sw-draw-skill\requirements.txt
python -m pip install --no-index --find-links=D:\wheels -r D:\sw-draw-skill\requirements-cv.txt
```

## 6. 插件包传输

- 把 `sw-draw-skill-*.zip` 传到服务器后，再复制到 Windows 虚拟机共享目录，或直接通过虚拟机共享文件夹访问。
- 推荐先在 Ubuntu 宿主机解压，再用 KVM 的 virtio-fs / SMB 共享给 Windows 虚拟机。

## 7. 离线部署检查清单

- [ ] Windows 10/11 ISO 已下载并传到服务器
- [ ] SolidWorks 2018 安装包已下载并传到服务器
- [ ] KVM/QEMU 或 Proxmox 已安装（离线安装包已准备）
- [ ] Python 安装包已传到 Windows 虚拟机
- [ ] requirements 离线 wheels 已下载并传到 Windows 虚拟机
- [ ] 插件 zip 已解压
- [ ] `setup.bat` / `verify_env.py` 可运行
- [ ] MCP SSE 服务可启动，FastGPT 可访问
