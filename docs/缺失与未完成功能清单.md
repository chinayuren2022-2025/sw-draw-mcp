# 缺失与未完成功能清单

> 本清单只汇总“当前尚未完成或未完全可靠”的功能；已明确不做（钣金、焊件、爆炸视图、完整设计表）另列在文末。

## 1. full_round 全圆角

- **状态**：未完成
- **模块**：`sw_features.full_round_fillet`
- **详细说明**：
  - 已按 SW2018 TLB v26 修正 Ftyp/Options 常量。
  - `FeatureManager.FeatureFillet/FeatureFillet3/FeatureFillet5` 均返回 `None`。
  - `IModelDoc2.FeatureFillet3` 返回 `1`，但特征树未实际生成全圆角特征。
  - 已尝试多组 face 选择 mark（1/2/4、1/4/2、2/1/4 等）、多组 Options 位掩码、NRadii/Radii 数组，均未成功。
- **建议**：后续可通过录制宏对照 SW2018 UI 实际生成的全圆角参数和选择顺序，再精确复现 API 调用。

## 2. create_feature_folder 特征树文件夹

- **状态**：未完成（尝试后跳过）
- **模块**：`sw_features.create_feature_folder`
- **详细说明**：
  - 按 SW2022 可用方式测试 `FeatureManager.InsertFeatureTreeFolder2(1)`，并预选特征。
  - SW2018 中返回 `None`，特征树无新增文件夹。
  - 网上的可用代码主要针对 SW2022，SW2018 行为不同。
- **建议**：如确需特征树文件夹，可在零件模板中预置，或改用 UI/宏录制方式。

## 3. flex 弯曲

- **状态**：未完成
- **模块**：`sw_features.flex`
- **详细说明**：
  - `InsertFlexFeature` 在 SW2018 中返回 `None`。
  - 即使预选实体，仍未成功。
  - 参数顺序/枚举值与 SW2018 实际签名可能不匹配。
- **建议**：通过宏录制获取 SW2018 实际 `InsertFlexFeature` 参数后修复；如不需要可保持占位。

## 4. deform 变形

- **状态**：占位
- **模块**：`sw_features.deform`
- **详细说明**：
  - SW2018 FeatureManager 未公开可靠的 Deform 创建签名。
  - 当前函数会尝试 `InsertDeform`/`FeatureDeform`，失败后抛出清晰错误。
- **建议**：若需要，用 flex/放样/边界等替代建模路径，不承诺 SW2018 API 原生支持。

## 5. 装配配合类型完整实机复核

- **状态**：部分完成
- **模块**：`sw_assembly_full.add_mate_full`
- **详细说明**：
  - 已封装 AddMate3/4/5 和大部分 mate type。
  - 实测确认：coincident、distance、parallel、concentric 等基础类型可用。
  - 其他类型（相切、对称、宽度、路径、齿轮、锁定、线性耦合、轮廓中心、槽口、铰链等）尚未逐一实机验证。
  - `lock_rotation`/`width_option` 路径可创建配合，但返回 `error_code=1`，语义未完全确认。
- **建议**：后续按场景逐类型做集成测试。

## 6. DimXpert/MBD 高级标注

- **状态**：部分完成
- **模块**：`sw_annotate`
- **详细说明**：
  - 已实现：DimXpert 管理器、feature/annotation 计数、size/location/basic 尺寸、自动尺寸方案、删除公差。
  - 未实现：基准符号、几何公差（GTOL）、位置度、轮廓度、复合公差、Datum 高级设置等。
- **建议**：如需完整 MBD，按 `IDimXpertPart.InsertDatum` / `InsertGtol` 等继续扩展。

## 7. 渲染能力

- **状态**：基础完成
- **模块**：`sw_features.set_appearance` / `set_scene`
- **详细说明**：
  - 已实现：零件整体外观颜色（MaterialPropertyValues 九元组）、场景名设置。
  - 未实现：面/体/特征级独立外观、贴图、PhotoView 渲染、RealView 切换、光线/背景图、显示状态级材质。
- **建议**：作为可选扩展。

## 8. 子装配体解散

- **状态**：基本完成
- **模块**：`sw_assembly_full.dissolve_subassembly`
- **详细说明**：
  - 在简单自建子装配体上已实机通过。
  - 复杂子装配体（含嵌套/配合较多）尚未全面验证。
  - 之前 `bridge_asm` 场景失败可能与组件选择/路径有关，而非 API 本身。

## 9. 中性格式导入导出

- **状态**：未实现
- **模块**：无
- **详细说明**：
  - 未实现 STEP/IGES/Parasolid/STL/3D PDF 导出，也未实现对应导入。
  - 当前只支持保存 SLDPRT/SLDASM。
- **建议**：后续按 `IModelDocExtension.SaveAs2/3` 和 `LoadFile4` 扩展。

## 10. 零件特征编辑/回滚条高级管理

- **状态**：部分完成
- **模块**：`sw_features.rollback_feature` / `rollforward_feature` / `reorder_feature` / `rename_feature`
- **详细说明**：
  - 已实现回滚、回退、重排、重命名。
  - 未实现：特征参数回读后修改（Edit Definition）、特征树文件夹、特征拖放、冻结栏等。

## 11. 工程图出图

- **状态**：未实现
- **模块**：无
- **详细说明**：
  - 不创建工程图文档、三视图、剖视图、尺寸/公差/注解/BOM。
  - 当前只做“读图 → 建模 → 回拍对比”。
