# sw-draw-skill 插件功能与用途总结

## 1. 插件定位

`sw-draw-skill` 是一个面向 **SolidWorks 2018** 的参数化建模插件，目标是通过自然语言/结构化 spec 自动完成零件建模、装配体建模和工程图零件识别建模。

它运行在 **Windows + SolidWorks COM** 环境，由 Python 确定性执行几何计算和 SW API 调用，不依赖用户手动操作。

## 2. 核心用途

- 把自然语言需求转换为 SolidWorks 零件/装配体
- 根据工程图 PDF/图片读取尺寸和视图，自动建模并回拍对比
- 作为 MCP 工具供 LLM 智能体调用
- 作为 CLI 脚本批量/确定性建模
- 为 SolidWorks 二次开发提供可复用的特征层、草图层、装配层封装

## 3. 已实现功能

### 3.1 SolidWorks 基础管理
- 自动连接/启动 SolidWorks，TLB 版本自适应（SW2018 v26）
- 新建/打开/保存/关闭零件和装配体
- 模板查找、重建、质量属性、特征树遍历
- 多文档管理、全局串行锁

### 3.2 草图能力
- 直线、中心线、圆弧、圆、椭圆、样条、矩形、多边形、槽口、点、文字
- 草图圆角/倒角、修剪/延伸、等距、镜像、阵列、移动/复制/旋转/缩放
- 转换实体、交叉曲线
- 线性/径向/直径/角度尺寸、驱动/从动、公差
- 几何关系添加/删除、全自动约束

### 3.3 零件特征
- 拉伸凸台/切除、旋转、扫描、放样、边界、加厚
- 圆角（constant/variable/face 已可用）、倒角、壳、拔模、筋、圆顶、包覆
- 简单孔、异型孔向导（simple/counterbore/countersink/tapped）
- 装饰螺纹（CosmeticThread）
- 线性/圆周/草图驱动/曲线驱动/表格驱动/填充阵列、镜像
- 组合/分割/压凹/型腔、移动复制实体、缩放、弯曲、变形（占位）
- 特征树管理：回滚、回退、重排、重命名
- 材料、自定义属性、配置、方程式
- 外观颜色、场景设置（基础渲染）

### 3.4 参考几何 / 曲线 / 曲面
- 基准面、基准轴、参考点、坐标系
- 螺旋线/涡状线、投影曲线、组合曲线、分割线、XYZ/点曲线
- 拉伸/旋转/放样/边界/平面/填充曲面
- 等距/延伸/修剪/解除修剪/缝合曲面
- 曲面切除、替换面

### 3.5 装配体能力
- 新建/打开/保存装配体
- 插入零部件（零件和子装配体）、配置选择
- 配合：重合、同心、距离、角度、平行、垂直、相切、对称、宽度、路径、齿轮、锁定、线性耦合等（代码已封装，部分类型待实机复核）
- 组件管理：固定/浮动、压缩/还原/轻化、显示/隐藏、替换、删除、移动、虚拟零件、虚拟装配
- 组件线性/圆周阵列、镜像、草图驱动/派生阵列
- 装配干涉检查、质量属性、重建报告
- 装配切除、孔系列、配合参考
- 子装配体：插入、查找、进入编辑、解散（已实机验证简单场景）

### 3.6 工程图读图建模工作流
- `drawing_ingest`：PDF/图片解析，提取视图、尺寸、文本
- `drawing_interpret`：视图理解（默认不依赖 OpenCV）
- `drawing_spec`：结构化建模 spec 执行器
- `capture_model_views`：多视角截图导出
- `model_view_compare`：模型视图与图纸视图对比（默认 side-by-side）
- 已用 mm25-p1-1.pdf 完整跑通回归

## 4. 使用方式

### 方式一：DeepSeek harness
```bash
python harness/deepseek_harness.py "画一个Φ25、f=50的平凸透镜"
```

### 方式二：MCP 客户端
```json
{
  "solidworks-draw": {
    "command": "D:\\FastProgram\\python\\python.exe",
    "args": ["-X", "utf8", "D:\\sw-draw-skill\\scripts\\mcp_server.py"]
  }
}
```

### 方式三：CLI
```bash
python scripts/build_lens.py --params '<JSON>'
python scripts/drawing_ingest.py <drawing.pdf>
python scripts/drawing_spec.py examples/mm25/drawing_spec.json
python scripts/capture_model_views.py
python scripts/model_view_compare.py <drawing.json> <views>
```

## 5. 运行环境

- Windows + SolidWorks 2018 SP5（其他版本需重新生成 TLB 缓存）
- Python 3.10+（开发环境 3.14.2）
- 核心依赖：`pywin32`、`mcp`、`pymupdf`、`Pillow`
- 可选依赖：`opencv-python-headless`（仅 `--cv` 深度识别需要）
- WSL 桥接：`bridge/` 下 PowerShell 7 脚本

## 6. 明确不在范围内

- 钣金
- 焊件
- 装配体爆炸视图
- 完整设计表
- 工程图出图（图纸创建/注解/BOM）
- 纯矢量工程图的深度解析（暂不做）
