# 桌面 MCP 客户端接入说明（WorkBuddy / Kimi Work / ChatGPT）

## 1. 前提

- 已运行 `setup.bat`，Python 和依赖正常。
- 已安装 SolidWorks 2018，并至少启动过一次（COM 注册）。
- 桌面客户端支持 MCP server。

## 2. 通用配置（stdio）

在客户端 MCP 设置中新增 server：

```json
{
  "mcpServers": {
    "solidworks-draw": {
      "command": "D:\\FastProgram\\python\\python.exe",
      "args": [
        "-X",
        "utf8",
        "D:\\sw-draw-skill\\scripts\\mcp_server.py"
      ],
      "env": {
        "SW_DRAW_OUTPUT": "D:\\sw-draw-skill\\output"
      }
    }
  }
}
```

> 如果客户端配置里没有 `env` 字段，可省略；`output/` 仍会作为默认输出目录。

## 3. 各客户端说明

### 3.1 腾讯 WorkBuddy

- 支持 MCP server 配置时，直接导入上面的 stdio 配置。
- 如果 WorkBuddy 只支持 HTTP/SSE，则使用：
  ```bat
  python D:\sw-draw-skill\scripts\mcp_server.py --transport sse --host 127.0.0.1 --port 8711
  ```
  MCP URL：
  ```text
  http://127.0.0.1:8711/sse
  ```

  > `127.0.0.1` 表示**仅本机可访问**。如果 WorkBuddy / Kimi / ChatGPT
  > 桌面客户端与 SolidWorks 运行在同一台 Windows 上，这个地址就够用。
  > 如果客户端在另一台机器/云端，则需要把 `--host` 改为 `0.0.0.0`，
  > 并配置防火墙；出于安全考虑，不建议跨公网直接暴露。

### 3.2 Kimi Work

- 同样优先使用 stdio 配置。
- 如 Kimi Work 对 `command/args` 有沙箱限制，可改用 SSE。

### 3.3 ChatGPT（桌面版 / Codex）

- Codex 支持 MCP server 注册，例如在 `~/.codex/config.toml`：
  ```toml
  [mcp_servers.solidworks-draw]
  command = "D:\\FastProgram\\python\\python.exe"
  args = ["-X", "utf8", "D:\\sw-draw-skill\\scripts\\mcp_server.py"]
  ```
- ChatGPT 桌面版如有 MCP 设置入口，同样导入 stdio 配置。
- 如果 ChatGPT/Codex 无法直接调用 MCP 工具，可让 Agent 读取 `AGENT_USAGE.md` 和 `docs/MCP_TOOLS.md`，再通过配套的 CLI 兜底脚本执行（如后续提供 `cli_agent.py`）。

## 3.5 “专属技能/插件”与 MCP 的关系

- **MCP 插件**：提供实际执行能力（本插件的 `mcp_server.py`）。
- **平台“技能”**：是 Agent 侧的提示词/规则/流程封装，例如 WorkBuddy 技能、
  Kimi 技能、ChatGPT GPTs/Codex instructions。
- 本插件已经提供 `SKILL.md` 和 `AGENT_USAGE.md`，可作为技能内容。
- 如果 WorkBuddy / Kimi Work / ChatGPT 桌面版要求“专属技能包/技能描述文件”，
  **不需要重写核心插件**，只需为每个平台准备一份轻量技能清单，内容为：
  - 本插件的用途和限制
  - MCP server 启动/配置方式
  - 常用工具调用顺序
  - 任务模板
- 样例文件放在 `agent-configs/`：
  - `workbuddy-skill.md`
  - `kimi-skill.md`
  - `chatgpt-codex-skill.md`

## 4. 配置后验证

1. 在桌面客户端中查看是否出现 `solidworks-draw` 工具列表。
2. 调用 `sw_status`，应返回：
   ```json
   {"running": true, "revision": "26.5.0", "active_doc": "..."}
   ```
3. 调用 `lens_dry_run` 测试参数预览。
4. 调用 `part_build` 测试简单零件。

## 5. 常见问题

| 现象 | 处理 |
|---|---|
| 客户端找不到 MCP server | 检查 `command`/`args` 中的 Python 路径和脚本路径 |
| `sw_status` 返回 running=false | 先启动 SolidWorks，或确认 COM 注册 |
| 工具调用超时 | 首次 COM 缓存生成较慢，可先手动运行 `verify_env.py` |
| 输出路径不对 | 设置 `SW_DRAW_OUTPUT` 环境变量 |
