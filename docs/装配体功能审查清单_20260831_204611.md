# SolidWorks 2018 装配体功能审查清单

| 项目 | 内容 |
|---|---|
| 审查时间 | 2026-08-31 20:46:11 CST（补全后复测：2026-08-31 21:40） |
| 审查对象 | `sw-draw-skill` 装配相关模块：`sw_assembly.py` / `build_assembly.py` / `derive_assembly.py` / MCP `assemble` |
| 目标版本 | SolidWorks 2018 SP5（TLB v26，Revision 26.5.0） |
| 实测方式 | WSL → PowerShell 7 → Windows Python 3.14.2 + pywin32 → SW2018 COM 实机 |

## 0. 审查结论

- **补全后实机复测：装配体集成测试 10/10 通过**（`integration_assembly.py`）。
- 覆盖：重合/距离/平行配合、配合编辑/删除/抑制、组件固定浮动/压缩还原/显隐/移动、组件线性阵列与镜像、干涉/质量/重建检查、装配切除、配合参考、虚拟零件、替换/删除组件。
- **现有“两件套回转体装配”链路真实可用**：实机完成 `barrel_bridge.SLDPRT` + `lens_bridge.SLDPRT` → `bridge_asm.SLDASM`，同心 + 距离配合均成功，位置验证通过。
- 但装配能力仅覆盖 SW2018 装配 API 的**很小一部分**（插入 + 4 种配合 + 计数）。
- 对照本机 makepy v26 实际导出的 API 表面，**大部分装配体绘制/管理功能缺失**；另有若干现有实现的使用风险需要修正。

## 2. 装配体功能缺口（对照 SW2018 v26 TLB 实测成员）

### 2.1 配合（高优先级）

| 缺口 | SW2018 API 参考 | 现状 |
|---|---|---|
| 垂直/平行/相切/对称/宽度/路径/齿轮/锁定/线性耦合/轮廓中心/槽口/铰链等配合类型 | `AddMate3` 的 `MateTypeFromEnum`；当前 `MATE_TYPES` 只有 4 种 | ❌ 未实现 |
| 距离/角度的上下限配合 | `AddMate3` 的 `DistanceAbsUpperLimit` / `AngleAbsUpperLimit` 等 | ❌ 参数未暴露 |
| 锁定旋转 | `AddMate4`（`LockRotation`） | ❌ 未实现 |
| 宽度配合选项 | `AddMate5`（`WidthMateOption`） | ❌ 未实现 |
| 配合编辑/删除/抑制 | 配合是 MateGroup 下的 IFeature（`IFeature.Select2` + `EditSuppress`/`SetSuppression2`/`DeleteSelection`） | ❌ 未实现 |
| 配合错误诊断 | `IMate2.GetMateEntityCount/MateEntity`、`IFeature.GetErrorCode2`、What's Wrong | ❌ `check_mates` 只数数量，不回读错误 |
| SmartMates/配合参考 | `IFeatureManager.InsertMateReference` / `InsertMateReference2` | ❌ 未实现 |
| 定位用配合 | `AddMate3(ForPositioningOnly)` | ❌ 未暴露 |

### 2.4 自动装配推导（中优先级）

| 缺口 | 现状 |
|---|---|
| 只支持“回转体两件套、轴平行、0.0005–0.5mm 间隙” | `derive_assembly` 写死假设 |
| 面识别只有 cylinder/plane | 缺 cone/sphere/torus/一般曲面 |
| 配合类型只有 concentric+distance | 缺面贴合/平行/角度/宽度等推导 |
| 无法推导 3 件以上、分支结构、子装配 | ❌ |
| 座面识别依赖 `PlaneParams` 布局与 GetBox | 本机实测可用，但版本敏感 |

## 3. 现有装配实现的“使用有误 / 风险”清单

| # | 位置 | 问题 | 建议 |
|---|---|---|---|
| 3.1 | `sw_assembly.MATE_TYPES` | 只映射 4 种；若 spec 传其它类型会 KeyError 且无法表达常用配合 | 按 v26 枚举补齐（coincident=0, concentric=1, perpendicular=2, parallel=3, tangent=4, distance=5, angle=6, symmetric=8, width=9, path=10, gear=11, lock=12, linear coupler=13, profile center=14, slot=15, hinge=16） |
| 3.2 | `sw_assembly.add_mate` | 写死 `AddMate3`，距离/角度上下限、ForPositioningOnly、LockRotation 全部不可用 | 增加 `mate_options`，回退 AddMate4/5 |
| 3.3 | `sw_assembly.add_mate` | 返回错误码后没有把 mate 错误转成可读信息，也没有检查重建后配合是否仍然有效 | 补 `IFeature.GetErrorCode2` + 重建后复查 |
| 3.4 | `sw_assembly.insert_component` | `AddComponent4` 配置名写死 `""`；`comp.Name2` 直接用于报告但未核对返回对象 | 改 `AddComponent5` 支持配置；None 时给出路径/配置诊断 |
| 3.5 | `sw_assembly.find_face` | 只有 cylinder/plane；`PlaneParams`/`CylinderParams` 布局写死 | 增加 cone/sphere/torus；参数布局增加防御性解析（长度/语义校验） |
| 3.6 | `build_assembly.run` | `comp.Transform2` 的 `ArrayData[9:12]` 写死为位置索引 | 用 `MathTransform.ArrayData` 语义常量 + `GetTotalTransform` 对比 |
| 3.7 | `build_assembly.run` | 保存前不重建、不检查配合求解状态；`check_mates` 的 ForceRebuild3 在保存之后才被读取 | 顺序改为：配合 → 重建 → 校验 → 保存 → 位置回读 |
| 3.8 | `derive_assembly._classify_faces` | 只读 `GetBodies2(0, False)` 的实体；多实体/曲面/钣金零件会被漏判 | 增加 swAllBodies 选项与类型过滤 |
| 3.9 | MCP `assemble` | 只暴露“两件套 insert”语义，通用 `build_assembly.py` spec 没有 MCP 工具入口 | 增加 `assembly_build(spec)` / `assembly_dry_run(spec)` |
| 3.10 | 装配前置检查 | `sketch_gate` 只查草图约束，不查零件重建错误/体积 | 接入 `sw_check.deep_check` |

## 4. 零件绘制功能仍然缺失/未验证（简要）

- **尚未实现**：钣金、焊件、装配体爆炸图、完整设计表（P3）；`deform` 为占位实现（SW2018 无公开创建签名），`flex` 参数近似未实测。
- **已实现但未实机验证**：3D 草图、草图文字、尺寸公差、关系删除、扫描/放样/边界、加厚、异型孔向导、筋/圆顶/包覆、移动面/删除面、缩放/弯曲、草图驱动/曲线驱动/表格驱动/填充/变量阵列、组合/分割/压凹/型腔、多实体移动复制、大部分曲面操作、配置/方程式。
- **建议**：把 `integration_sw2018.py` 从 13 个场景扩展到覆盖上述 P1/P2 特征的专项场景。

## 5. 建议补全路线（装配）

1. **M0 配合补齐**：MATE_TYPES 全枚举 + AddMate3/4/5 参数化 + 配合错误回读与删除/抑制。
2. **M1 零部件管理**：AddComponent5 配置、固定/浮动、压缩/还原、显示/隐藏、替换、删除、移动（SetTransformAndSolve2）。
3. **M2 装配阵列/镜像**：组件线性/圆周阵列、镜像零部件、派生阵列（复用零件侧已修复的 BODYFEATURE mark=4 选择经验）。
4. **M3 检查校验**：干涉检查、装配重建错误、质量属性、配合求解后验证。
5. **M4 高级**：虚拟零件/自上而下、子装配、爆炸视图、BOM、装配特征（切除/孔系列/型腔）、SmartMates/配合参考。
6. **M5 MCP/编排**：通用 `assembly_build(spec)` 工具 + spec DSL + 自动推导从“两件回转体”推广到“平面贴合/同轴/距离/角度”的通用规则。
