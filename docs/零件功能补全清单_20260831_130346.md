## 0. 使用说明

1. 每完成一项，把 `[ ]` 改为 `[x]`，并在"实现记录"栏填写文件名、函数名与测试样例。
2. 表中 API 名称为实现参考（SW2018 常用接口），**必须**以 SW2018 makepy 缓存（v26 TLB）生成的实际签名为准，换版本后重跑 `gencache.EnsureModule`。
3. 所有新增实现必须遵守包内既有约定：
   - 内部长度单位为**米**，外部参数为毫米（沿用 `sw_core.mm()`）；
   - 涉及 VARIANT/ByRef 参数走后期绑定（参考 `sw_core.save_as`）；
   - MCP 工具调用前 `CoInitialize`、全程全局执行锁（参考 `mcp_server._call`）；
   - 特征失败必须回传 errors/warnings 错误码，不允许静默跳过（倒角除外，需改造为可报告）；
   - 建模前先 dry-run 推导参数、建模后做体积/几何/草图约束校验。
4. 优先级定义：
   - **P0**：通用基础零件必备（没有它们仍只能做回转体）；
   - **P1**：常见机械零件必备；
   - **P2**：复杂曲面/曲线与高级编辑；
   - **P3**：可选扩展（钣金、焊件等）。
