# 移植与打包说明（Windows + SolidWorks 2018 + 桌面 MCP 客户端）

## 1. 目标环境

- Windows 10/11 64 位
- SolidWorks 2018 SP5（COM 已注册）
- Python 3.10+（可选自动安装）
- 桌面客户端：
  - 腾讯 WorkBuddy
  - Kimi Work
  - ChatGPT（桌面版 / Codex）
- 使用方式：**MCP 桌面客户端接入**，不是 CLI 手动调用。

## 2. 打包方式：单包 + 可选运行环境

建议不再拆成多个包，而是交付**一个 `sw-draw-skill-win.zip`**，内含：

```text
sw-draw-skill/
├─ scripts/
├─ bridge/
├─ docs/
├─ examples/
├─ knowledge/
├─ output/
├─ agent-configs/
├─ README.md
├─ SKILL.md
├─ AGENT_USAGE.md
├─ requirements.txt
├─ requirements-cv.txt
├─ setup.bat          # 环境检测 + 可选安装 Python
├─ verify_env.py      # 环境自检
└─ mcp.*.example.json
```

### 2.1 使用流程

1. 解压到 `D:\sw-draw-skill`
2. 双击或命令行运行 `setup.bat`
3. `setup.bat` 会：
   - 检测 `python` / `py`
   - 如果没检测到 Python，**询问用户是否自动安装**
     - 选 `Y`：尝试用 `winget install Python.Python.3.12`
     - 选 `N`：跳过 Python 安装，只做后续环境提示
   - 检测 SolidWorks COM
   - 安装核心依赖 `requirements.txt`
   - 生成 SW2018 COM 缓存
   - 运行 `verify_env.py`
4. 启动 MCP server 供桌面客户端接入

> 如果用户选择“不安装 Python”，插件核心功能无法运行，但脚本会明确提示用户需要手动安装；不会强制安装。

### 2.2 可选依赖

默认只装：

```text
pywin32
mcp
pymupdf
Pillow
```

`opencv-python-headless` 放入 `requirements-cv.txt`，默认不装。只有需要 `--cv` 深度识别时才安装，减少移植成本。

## 3. 桌面客户端接入（MCP）

### 3.1 WorkBuddy / Kimi Work / ChatGPT 桌面版

这些桌面客户端通常支持 MCP server 配置（stdio 或 SSE）。

#### 推荐：stdio

```json
{
  "mcpServers": {
    "solidworks-draw": {
      "command": "D:\\FastProgram\\python\\python.exe",
      "args": [
        "-X",
        "utf8",
        "D:\\sw-draw-skill\\scripts\\mcp_server.py"
      ],
      "env": {
        "SW_DRAW_OUTPUT": "D:\\sw-draw-skill\\output"
      }
    }
  }
}
```

#### 如果客户端不支持 stdio：SSE

```bat
python D:\sw-draw-skill\scripts\mcp_server.py --transport sse --host 127.0.0.1 --port 8711
```

桌面客户端 MCP URL 填：

```text
http://127.0.0.1:8711/sse
```

### 3.2 桌面客户端配置样例

`agent-configs/` 中可分别提供：

- `workbuddy-mcp.json`
- `kimi-mcp.json`
- `chatgpt-mcp.json`
- `codex-config.toml`

每个文件只改 `command` 和 `args` 中的 Python/路径。

## 4. 如何让桌面 Agent 正确读取和使用插件

### 4.1 根目录 `AGENT_USAGE.md`

桌面客户端会读取项目说明时优先看到的文件。内容必须简洁、可执行：

- 先 `sw_status`
- 建模前先 dry-run
- 单位毫米
- 不做的范围
- 完成后返回绝对路径

### 4.2 `docs/MCP_TOOLS.md`

19 个 MCP 工具速查表：工具名 / 用途 / 关键参数 / 示例。

### 4.3 `docs/AGENT_TASKS.md`

常见任务模板：透镜、工程图建模、装配、装饰螺纹、DimXpert、子装配体。

### 4.4 MCP 工具 docstring 自包含

每个工具说明必须包含：

- 功能一句话
- 参数单位/必填/可选
- JSON 示例
- 返回字段
- 不做什么

### 4.5 环境变量

- `SW_DRAW_OUTPUT`
- `SW_DRAW_TEMPLATE`
- `SW_DRAW_CV`

统一使用环境变量，避免 Agent 硬编码路径。

## 5. 落地步骤

```bat
:: 1. 解压
tar -xf sw-draw-skill-win.zip -C D:\

:: 2. 环境检测/安装
D:\sw-draw-skill\setup.bat

:: 3. 自检
python D:\sw-draw-skill\verify_env.py

:: 4. 启动 MCP（桌面客户端 stdio 模式通常自动拉起，无需手动）
::    若需要 SSE：
python D:\sw-draw-skill\scripts\mcp_server.py --transport sse --host 127.0.0.1 --port 8711

:: 5. 在 WorkBuddy / Kimi / ChatGPT 桌面客户端中导入 MCP 配置
```

## 6. 移植注意事项

- 所有示例路径使用 `D:\sw-draw-skill\...`，不要出现 WSL UNC 路径。
- 不依赖 `.pip-deps`。
- SolidWorks 模板路径由 `sw_core.find_part_template()` 自动搜索。
- SW2018 COM 注册必须存在；首次运行自动生成 makepy 缓存。
- 若桌面客户端不支持 MCP，需要额外开发适配器，而不是使用 CLI。
